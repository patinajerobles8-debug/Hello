# BillyUpClone (iOS SwiftUI concept)

Propuesta de app para iPhone inspirada en una experiencia de bienestar y entrenamiento estilo "Billy Up". El objetivo es mostrar una interfaz moderna con motivación diaria, programas guiados, comunidad y perfil.

## Qué incluye
- **Inicio** con mensaje motivacional, reto del día, progreso semanal y check-ins recientes.
- **Programas** con filtros rápidos y detalle de cada plan.
- **Comunidad** con publicaciones y acciones básicas.
- **Perfil** con objetivos y preferencias.

## Estructura
```
BillyUpClone/
├── BillyUpCloneApp.swift
├── Models/
├── Supporting/
├── ViewModels/
└── Views/
```

## Cómo usar en Xcode
1. Crea un nuevo proyecto iOS App (SwiftUI).
2. Reemplaza el contenido generado por los archivos de `BillyUpClone/`.
3. Asegúrate de añadir los archivos al target principal.

## Nota
Este es un concepto visual y de flujo; no incluye persistencia ni networking.
